HangMan — C++ Console Game

Jan 2025

The classic word game, played in the terminal. A random word is drawn from a built-in library, and the player guesses one letter at a time while an ASCII gallows gains a body part with each miss — six misses and the game is over.

The code is split into two classes: Game holds the word, the revealed answer, missed letters and the miss count, while Message handles all output, from the title screen and gallows art to the win and lose banners. Input is validated so only new letters are accepted.
